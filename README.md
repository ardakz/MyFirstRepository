Практикую GIT , Не буду копировать чужой проект , начну с самого начала 

Начал:
1. git init -- инициализация git 
2. git status -- просмотр статуса файлов
3. git add .  -- добавить файлы в промежутетное состояние
4. git commit -m "Первый commit"    -- commit
5. git remote add origin url.git    -- доступ к GitHub.
6. git log  -- показывает commits
7. git checkout  -- переход на пред commit  или  на другой ветку
8. git restore -- откат до commit с удалением изменении. 
9. git restore --staged file_name   -- убирает состояние git add
10. git commit --amend -m "Сообщение" -- меняет название commit
11. git push origin master  -- залить код в Github,сначала нужно сделать commit.
